It's `Sphere-Task-1`, built during my Web Development internship at **Sphere Consulting** (Lahore, Pakistan).

## 🧱 What's in this project

| File | Purpose |
|---|---|
| `index.html` | Page structure — nav, hero, about, skills, projects, and contact sections |
| `style.css` | All styling — layout, gradients/glow effects, skill gauges, project cards, responsive behavior |

### Page sections
- **Hero** — intro headline + call-to-action buttons (`View projects`, `Contact me`)
- **About** — short bio and focus areas (Red Team leaning, Full-stack learning)
- **Skills** — animated gauge cards (Python & C++, HTML & CSS) plus a tag row (Git, SQL/SQLite, REST APIs, Render, Vercel, Linux)
- **Projects** — a grid of project cards linking to live/deployed apps
- **Contact** — internship note + Email / GitHub / LinkedIn links
